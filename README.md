# Kiran QA Portfolio

A responsive personal portfolio website focused on QA Engineering, Manual Testing and Test Automation.

## Built with
- HTML5
- CSS3
- JavaScript
- Devicon technology icons
- Google Fonts

## Run locally
Open `index.html` in your browser.

## GitHub Pages
This project is configured for a static GitHub Pages deployment. Keep the `Assets` folder and its relative paths when publishing.

## Before publishing
- Confirm that `Assets/Kiran-resume.pdf` exists (or update the resume link).
- Confirm the LinkedIn and email details.
- Replace planned project cards with real repositories only after those projects are completed.
- Add a direct GitHub repository link for the Browser Autofill Extension Testing project when available.
